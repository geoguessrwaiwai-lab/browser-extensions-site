プライバシーポリシー

最終更新日: 2026年8月9日

Map Making App Tools（以下「本拡張機能」）は、個人情報、マップ情報、Cookie、その他のユーザーデータを外部へ収集、送信、販売または第三者と共有しません。機能設定とURLごとの設定については、以下のとおり利用者の端末内だけに保存します。

ページ内データの処理

本拡張機能は左右の画面幅を計算するため、ドラッグ中のポインター位置をブラウザ内で一時的に処理します。また、ぽちぽちモード中はロケーションの切り替わりと削除対象を判定するため、地点ID、pano ID、座標をページ内のメモリで一時的に処理します。これらを外部へ送信しません。

対象サイト

本拡張機能は、https://map-making.app/maps/数字形式のマップ編集ページでのみ動作します。Manifestの登録範囲内でも、このURL形式と対象要素が揃わないページでは機能を有効にしません。

外部通信と保存

本拡張機能は、外部サーバーとの通信、分析ツール、広告、外部JavaScript、Cookieを使用しません。storage権限を使用し、各機能の有効・無効、ぽちぽちモードの全体デフォルト、対象のマップURLとそのURLに対するON／OFF設定だけをchrome.storage.localへ保存します。これらの情報は利用者の端末内に保持され、外部へ送信されません。地点ID、pano ID、座標、選択履歴は保存しません。

案内サイトでのGoogle Tag Managerの利用

この案内サイトは、サイト上のタグを管理するためGoogle Tag Managerを読み込みます。ページの表示時にブラウザがGoogleのサーバーへ接続します。Google Tag Managerは案内サイトだけで使用し、本拡張機能には組み込まれていません。Googleによるデータの取り扱いには、Googleが定めるプライバシーポリシーが適用されます。

第三者サービス

Map Making Appは本拡張機能とは独立した第三者サービスです。本拡張機能は非公式であり、Map Making Appまたはその運営者との提携、承認、関係を示すものではありません。

ポリシーの変更

本ポリシーを変更した場合は、このページに最新版を掲載し、最終更新日を更新します。
