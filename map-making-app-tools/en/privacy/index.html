PRIVACY

Privacy Policy

Last updated: October 6, 2026

Map Making App Tools (the “Extension”) does not externally collect or transmit, sell, or share personal information, map data, cookies, or other user data. Feature preferences, per-URL preferences, and how you organize the folder view are stored only on the user's device as described below. For the way "Keep tag colours" adds a colour to Map Making App's own tag update request, see "Network access and storage".

On-page data processing

The Extension temporarily processes the pointer position in your browser while you drag the divider. While Pochi-pochi mode is enabled, it also processes location IDs, pano IDs, and coordinates in page memory to detect location changes and identify the previous location to delete. The folder view reads map names and location counts from the map list already on the page in order to draw the cards; it reads them from the page each time it renders and does not store them. "Keep tag colours" reads the tag name and colour entered in the tag edit form within the page, and uses them only to add the colour to Map Making App's own tag update request, as described under "Network access and storage". None of this information is transmitted externally.

Supported site

The Extension runs only on Map Making App editor pages whose URLs match https://map-making.app/maps/[number] and on the https://map-making.app/ home page. Even within the Manifest URL scope, it remains inactive unless both this URL format and the target element are present.

Network access and storage

The Extension uses no servers of its own, no third-party network requests, and no analytics, advertising, external JavaScript, or cookies. The single exception is "Keep tag colours". While that feature is on, saving a renamed tag makes the Extension add the colour to the tag update request Map Making App itself sends (PATCH https://map-making.app/api/maps/<ID>/tags) and resend it to that same destination. It includes only the tag name and colour, introduces no new destination, and adds no extra request. The request happens as a result of your own action in Map Making App, under your existing signed-in session.

It uses the storage permission to save only each feature's enabled state, the global Pochi-pochi default, the target map URL and that URL's ON/OFF setting, and how you organize the folder view (folder names you enter, the order of folders and maps, map identifiers, favorites, country codes, tag names and colors, the display language, and display preferences) in chrome.storage.local. This information remains on the user's device and is not transmitted externally. Location IDs, pano IDs, coordinates, selection history, map names, and map content itself are not stored.

Google Tag Manager on this website

This informational website loads Google Tag Manager to manage tags used on the site. Your browser connects to Google servers when a page is displayed. Google Tag Manager is used only by this website and is not included in the Extension. Google’s privacy policy applies to Google’s handling of data.

Third-party service

Map Making App is an independent third-party service. This unofficial Extension is not affiliated with, endorsed by, or connected to Map Making App or its operators.

Policy changes

If this policy changes, the latest version will be published on this page and the last-updated date will be revised.
