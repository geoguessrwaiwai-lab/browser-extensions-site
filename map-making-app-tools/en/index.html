Feature 1

Screen width adjustment

Feature 2

Pochi-pochi mode

Browse multiple selected locations in succession without saving them. Locations kept with Save or Close remain on your map while you “pochi-pochi” without cluttering it.

Configure each feature

Use Chrome's extension management page to enable or disable screen width adjustment and Pochi-pochi mode independently.

  1. Open the following URL in Chrome. chrome://extensions/
  2. Select “Details” for Map Making App Tools.
  3. Open “Extension options” and choose the features you want to use.

On the same page, enable “Default to ON” to start Pochi-pochi mode in the ON state for map URLs without a saved preference. A setting selected on a specific Map Making App URL is saved for that URL and takes priority over the global default. Saved URL preferences can be reviewed and changed in a scrollable list with partial URL search, then reset individually or all at once after confirmation. On page load, the mode turns on automatically once saved locations can be protected safely.

How to install

Install it in seconds from the Chrome Web Store.

  1. Use the button below to open the Chrome Web Store.
  2. Select “Add to Chrome.”
  3. Reload the Map Making App page to finish.
Install from the Chrome Web Store

We do not collect data

Location and pano IDs are processed only in page memory while the feature runs. Extension-local storage contains only feature preferences, the global default, the target map URL, and its ON/OFF setting; nothing is transmitted externally. See the privacy policy for details.
