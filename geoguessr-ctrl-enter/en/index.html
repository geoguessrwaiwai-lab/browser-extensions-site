Installation

Install the extension directly from the Chrome Web Store.

  1. Open the Chrome Web Store using the button below.
  2. Select “Add to Chrome.”
  3. Reload the GeoGuessr page to finish.
Install from the Chrome Web Store

No data collection

The extension does not collect, record, store, or transmit chat messages or keystrokes. See the privacy policy for details.
